# Changelog

## 0.6.1 - First public release

- Independent layouts for ultrawide and multiple monitors, including companion displays such as CORSAIR XENEON EDGE.
- Exact center widths, optional equal sides, Shift-drag placement, and app assignment.
- Chrome F11 confinement and YouTube pane fullscreen with companion 0.3.1.
- Direct interception of the YouTube fullscreen control, shortcut, video-element calls, and recovery of cached native requests.
- Restored non-Chrome app assignment and corrected reopening of hidden instances.
- Saved assignments, monitor fallback, recovery helper, per-user installer, and optional Windows startup.
- MIT-licensed source and reproducible Windows build.
